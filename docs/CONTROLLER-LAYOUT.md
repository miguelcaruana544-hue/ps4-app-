# Controller layout in Minecraft (built-in, no mod)

The launcher injects this automatically for Fabric, Quilt and Forge instances.
Toggle and tune it per instance: **Instance settings → Controller in Minecraft /
Controller look sensitivity / Controller stick dead zone**. Changes apply from the
next launch.

## In the game

| Button | Action |
| --- | --- |
| Left stick | Walk |
| Right stick | Look (sensitivity in settings) |
| Cross | Jump (hold) |
| Circle | Sneak (hold) |
| Square | Inventory |
| Triangle | Swap offhand |
| L2 | Mine / attack (hold) |
| R2 | Place / use (hold) |
| L1 / R1 | Hotbar left / right |
| D-pad left / right | Hotbar left / right |
| D-pad up | Toggle perspective (F5) |
| D-pad down | Drop item |
| Touchpad click | Open chat |
| L3 (left stick click) | Sprint (hold) |
| R3 (right stick click) | Pick block |
| Options | Pause menu |
| PS button | System (stays with the console) |

## In menus (inventory, settings, worlds...)

| Button | Action |
| --- | --- |
| D-pad / left stick | Move the selection (arrow keys) |
| Cross | Confirm (Enter) |
| Circle | Back (Escape) |
| Triangle | Previous control (Shift-Tab) |

Text fields and signs still open the console's own keyboard (unchanged).

## Notes

- Everything is pressed into the game's own key bindings, so your Minecraft key
  options still apply; the pad presses the same keys a keyboard would.
- If the Controlify mod is installed in the instance, it takes over and the
  built-in support stands down automatically - the two never fight.
- Pure vanilla instances (no loader) get the launcher's controller navigation but
  not in-game pad play, because the compatibility mod needs a mod loader.
- Worn stick drifting? Raise **Controller stick dead zone** (Small / Normal / Large).
